# رفيقي — تطبيق أندرويد

## البناء (GitHub Actions)
1. أنشئ مستودعاً جديداً على GitHub وارفع محتويات هذا المجلد كما هي (بما فيها مجلد `.github`).
2. افتح تبويب **Actions** ثم **Build APK** ثم **Run workflow**.
3. بعد دقائق ينزل ملف `rafiqi-apk` من أسفل صفحة التشغيل (Artifacts). فيه `app-release.apk`.

ملف التوقيع `app/rafiqi.keystore` للتثبيت المباشر فقط، فاحتفظ به كما هو حتى تتحدّث النسخ فوق بعضها.
